# OerstedGrok

Oersted 737 Line Lab — Android (Kotlin + Jetpack Compose) port.

This repository is a clean continuation of the Android port work.

- **Source of truth for simulation logic**: `reference/web/src/lib/sim/`
- **Already ported Kotlin sim core**: `app/src/main/java/com/oersted/trainer/sim/`
- **Original Oersted1 repo is left untouched**

## Current status
Simulation core is largely ported with parity tests.  
UI / cockpit panels are the main remaining work.

See `docs/HANDOFF.md` and `CLAUDE.md` for details.
